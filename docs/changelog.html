けんさくくん 更新履歴・リリースノート

「けんさくくん」の公式リリース予定、修正および機能改善の履歴です。

v1.0.0 正式版

Vector公開 初版確定 2026/10/01 (予定)

ソフトウェア配布サイト「Vector」での公式公開をもって、「けんさくくん v1.0.0」の初版確定といたします。Windows専用の有償級・超高速デスクトップツールとして正式リリース予定です。

初版リリース 主要機能一覧
  • 超高速インメモリ検索: 数百ファイルのExcel設計書・方眼紙をメモリにキャッシュし、条件変更時は数十秒以内で瞬時再検索
  • 多彩な対象・条件検索: セル値、シート名、ブック名、コメント、図形内テキストの検索・除外に対応
  • 高度なキーワード指定: 複数行OR検索、ワイルドカード（* / ?）あいまい検索、全半角・大文字小文字同一視
  • Excel出力と書式完全再現: 検索セル周辺（上下左右）の拡張セルプレビュー、背景色・文字色・取消線の忠実再現
  • 列名フィルタ機構: 一覧上の列ごとに値抽出・絞り込みが可能な FilteredDataGridControl 搭載
  • 100% 完全オフライン・安心設計: クラウド通信・データ送信ゼロ、レジストリ不使用のポータブル動作
  • セットアップ支援ツール同梱: スタートメニュー登録・アンインストール用のVBScriptを完備

v1.0.0 (先行プレリリース)

GitHub Releases 先行公開 2026/09/10
  • GitHub Releases にて kensaku-kun_v1.0.0.zip（自己完結型EXE）を先行配布開始
  • Windows SmartScreen 警告への対処ガイドおよび公式LP（日本語・英語）を開設
  • 動作検証用サンプルExcelデータセット（200件 / 600件 / 2000件）の提供開始
  • ライセンス管理モジュール（LicenseHelper）および試用期間管理の組み込み
