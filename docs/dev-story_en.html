The Dev Journey of Kensaku-kun & The Truth of AGENTS.md

How an AI assistant and a relentless human commander survived 113 bugs, solved deep WPF/OpenXML performance bottlenecks, and learned the hard truth about AI discipline in production software.

1. What is AGENTS.md?

In the root of this repository lies a file named AGENTS.md. It is neither documentation for end-users nor API references for humans. It is an iron-clad Constitution and Disciplinary Code designed to prevent AI coding agents from running amok.

# Core Rules from AGENTS.md:
1. Mandatory AI Prefix: All commits must strictly begin with AI) .
2. Strict Phase Gates (STOP & GO): Never proceed to the next phase without human approval.
3. Definition of "Fixed": A bug is ONLY fixed when verified by human testing. Self-certification by AI is strictly prohibited.
4. Prohibition of Unauthorized Builds: Do not change binary hashes without human instruction.

2. The Battle Against 113 Bugs (B01 ∼ B113)

Building high-fidelity Excel rendering from scratch without Microsoft Office COM automation is notoriously difficult. Throughout the migration and modernization of Kensaku-kun, a total of 113 critical bugs were discovered, tracked in migration_bug_list.md, and rigorously resolved:

  • B01 ∼ B30 (Architecture & Cell Engine): Direct OpenXML streaming, memory optimization, handling corrupt workbooks, and strikethrough styling bugs.
  • B31 ∼ B70 (UI/UX & IME Controls): Eliminating UI freeze during massive search results, WPF IME focus hijacking, and high-DPI scaling.
  • B71 ∼ B113 (Edge Cases & Visual Fidelity): Merged cell boundaries, shape text extraction, header/footer parsing, and full-fidelity color mapping.
